REDOX-ENCH is a split ergonomic keyboard by Positron Electronic, an independent
derivative of the Redox keyboard with a rotary encoder, OLED, Kailh hotswap
sockets and RGB underglow. It runs QMK firmware with VIA support on an Arduino
Pro Micro (ATmega32u4).
