Motorised astronomy filter wheel (up to 9 filters). STM32G0B1 firmware with native USB CDC
(PlatformIO/Arduino), TMC2209 stepper driver, hall-sensor position detection and I2C EEPROM
calibration storage. Controlled by an ASCOM driver and a Python GUI over a USB serial protocol.
