PicoI2S: USB audio interface firmware for the RP2350 (Waveshare
RP2350-One, Raspberry Pi Pico 2). USB Audio Class 2.0, asynchronous with
a feedback endpoint, 32 to 96 kHz, 16 and 24 bit, to I2S, dual-line
multibit DACs (PCM56, AD1865, PCM1704, TDA1541A) through on-chip filters,
and S/PDIF, with an S/PDIF input. A jumper selects a USB Audio Class 1.0
compatibility mode at boot, under the same PID.
