Arduino Uno R3 form factor board based on the Microchip AVR64DU32 (native USB 2.0 full-speed, USB-C connector). This PID is used by sketches built with UkiUkiCore, an Arduino core derived from DxCore, and enumerates as a USB CDC serial port. The USB bootloader of the same board uses PID 4251. KiCad design files are in the `hardware/UkiUkiduino` directory of the source repository.
