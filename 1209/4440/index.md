Wakes is a semi-modular music synthesizer developed as open-source custom firmware for the 
Teenage Engineering SP-1, a commercial music device built on the nRF52840. Wakes runs ports 
of Mutable Instruments' Plaits and Marbles (MIT) on Zephyr. The project does not include hardware design.
This allocation is requested for the open USB device firmware, so every user who flashes Wakes gets the same
collision-free identity. The device exposes a CDC ACM console, a USB-MIDI 1.0 port, and a
USB audio class output stream.
