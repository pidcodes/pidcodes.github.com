An open-source 8-channel USB digital logic analyzer based on the Raspberry Pi RP2040 microcontroller.

The repository contains modifiable KiCad PCB design files, production Gerber files,
documentation, and firmware source code. The hardware design is licensed under
CERN-OHL-P-2.0 and the firmware is licensed under the MIT License.
