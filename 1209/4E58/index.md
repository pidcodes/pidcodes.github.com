NexusSDR is a USB SDR stick built around an NXP i.MX RT1011 bridge MCU and a
Semtech SX1255 I/Q transceiver (400–510 MHz). The repository contains the KiCad
schematic and PCB (CC BY-SA 4.0), the bare-metal TinyUSB firmware, a libusb host
library and a SoapySDR driver (GPL-2.0-or-later).
