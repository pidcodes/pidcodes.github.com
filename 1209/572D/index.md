AirDAP is a low-cost 2.4 GHz wired and wireless CMSIS-DAP debug probe and USB-to-serial adapter based on the WCH CH570/CH572. It provides a USB CDC ACM serial port and a CMSIS-DAP debug interface (SWO is not supported).

The firmware is MIT-licensed. The hardware design files are CERN-OHL-P-2.0 and are published on OSHWHub: [AirDAP](https://oshwhub.com/metro/project_oiadrnso) and [TinyDongle](https://oshwhub.com/metro/project_hfxfdchy).
