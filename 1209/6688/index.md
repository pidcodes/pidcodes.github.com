USB Sniffer 2 is an open-source USB 2.0/3.0 protocol analyzer.

Hardware (KiCad schematic and PCB) is licensed under GPLv3 and is available at:
https://github.com/vllogic/dalishen_pi_h7p20/tree/main/hardware/usb_sniffer_2

The FX2LP firmware and the `usb_sniffer` host tool are licensed under BSD-3-Clause and are available at:
https://github.com/vllogic/ataradov.usb-sniffer

The FPGA logic is licensed under BSD-3-Clause and is available at:
https://github.com/vllogic/dalishen_pi_h7p20/tree/main/examples/usb_sniffer_h7p20.ataradov.usb_sniffer

The firmware is built with the open-source SDCC compiler; see `firmware/Makefile` in the firmware repository.
