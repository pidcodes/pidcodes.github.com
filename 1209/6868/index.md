Three-channel CAN FD to USB adapter for the Artery AT32F456 (Cortex-M4), implementing the Geschwister Schneider gs_usb protocol (candleLight compatible).
Driver-free on Windows (WinUSB via MS OS 2.0 descriptors); on Linux via the gs_usb driver.
