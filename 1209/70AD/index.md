The Tuffpad is a one-handed gamepad combining a 20-key keypad, an analog stick, and a 5-way d-pad. It is built on an off-the-shelf RP2040 board (Raspberry Pi Pico) and runs open source CircuitPython firmware that presents a composite USB device (HID gamepad + keyboard, CDC serial for configuration). A companion open source management app configures profiles and bindings over serial.
