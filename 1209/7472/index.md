The truST runtime firmware for microcontrollers. A chip running it is an IEC 61131-3 PLC runtime that presents one USB CDC-ACM device, through which the truST command line and VS Code reach it with the same control protocol as truST on a computer. The firmware runs on off-the-shelf boards with a supported chip, first the STM32F4 family; there is no truST hardware design. Software licensed MIT OR Apache-2.0.
