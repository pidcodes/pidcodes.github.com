Enaga is open-source replacement firmware for the Sonicware SmplTrek family of portable
samplers (SmplTrek, Lofi-12 XT, CyDrums), which turns the unit into a platform for
instruments written as C++ apps. This ID identifies a unit running Enaga when it is
connected over USB: a class-compliant USB MIDI device, later joined by USB audio and
mass storage (SD card access) as a composite device.

Enaga is an independent project, not affiliated with or endorsed by Sonicware.
