OpenMUPP Probe is a multi-protocol programming and debug probe. It uses an STM32H523 microcontroller. One firmware image runs USB CDC, CMSIS-DAP v2 and EDBG (AVR) at the same time. The hardware design (KiCad) is licensed under CERN-OHL-S-2.0. The firmware is at [OpenMUPP/OpenMUPP](https://github.com/OpenMUPP/OpenMUPP) and is licensed under GPL-3.0.
