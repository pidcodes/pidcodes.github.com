OpenMUPP DFU Bootloader is the USB DFU 1.1 bootloader for the OpenMUPP firmware. It runs on the STM32F103 boards and on OpenMUPP v1 (CH32V307). It uses only the control endpoint, so `dfu-util` can write the application. It is licensed under GPL-3.0-or-later.
