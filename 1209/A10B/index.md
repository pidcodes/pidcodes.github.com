A replacement PCB for the Commodore Amiga 1000 keyboard, for Cherry MX switches. An ATmega32U4
replaces the original mask-ROM controller and speaks both the Amiga keyboard protocol and USB HID
(boot keyboard, built on LUFA), with the Amiga cable and USB-C live at the same time. Firmware
ported from Henryk Richter's A500KB.
