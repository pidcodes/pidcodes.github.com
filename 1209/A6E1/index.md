Agent Micro is open-source replacement firmware for the CH552-based SinLoon
SL2024502 commercial six-key, one-encoder macro pad, together with open-source
host-side flashing tools. The project does not manufacture or redesign the
third-party PCB and therefore has no PCB design files. This allocation is
requested for the open USB device firmware so every user can flash the same
collision-free identity. The device exposes keyboard, consumer-control, and
vendor Raw HID interfaces.
