Volna's firmware updater for the M-VAVE FM-1 enumerates as a USB MIDI device and accepts firmware updates over SysEx. It exposes a different set of USB interfaces from the regular USB Audio and MIDI application. The separate PID gives hosts a distinct USB identity for the update mode.
