Aemeath is an open-source virtual audio console for Windows. It provides 8 virtual inputs and 8 virtual outputs as software-emulated USB Audio Class 2.0 devices, served over USB/IP and attached through the usbip-win2 VHCI driver, so they bind to the in-box Windows USB audio class driver without test signing. Input and output devices share this PID and are told apart by bcdDevice.
