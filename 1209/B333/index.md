Open-source replacement firmware for the TheoryBoard THY333, a 96-pad USB MIDI
controller (STM32F407). The firmware is a USB MIDI class device (TinyUSB) that plays
chords and melodies by scale degree, with an arpeggiator, strum, presets and a web
editor over SysEx. Users install it from the browser through the board's own update
mode. Sources, build and tests are in the repository; the hardware itself is a
commercial product, so there are no PCB files.
