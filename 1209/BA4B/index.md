Open source firmware for a civilian 433 MHz LoRa mesh that carries text messages across a city without other infrastructure. It runs on the LILYGO T-Echo (nRF52840 and SX1262), written in Rust on embassy-nrf. The USB interface is a CDC-ACM serial port that carries the node's log and its measurement console.
