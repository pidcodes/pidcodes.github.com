An evaluation tool for determining where a user can and cannot see, effectively mapping a user's blind spots, similar to a Goldmann Visual Field Exam. The Retina Mapper is designed to be a small, battery powered personal evaluation tool with an optional HIPPA compliant web connection to your primary care provider or ophthamologist for convenient periodic retinal evaluations.
