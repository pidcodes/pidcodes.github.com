A software USB Audio Class 2.0 playback/capture device, transported over localhost USB/IP on Windows. The USB implementation and its native transport client are open source. Installations use distinct serial numbers under one PID. No physical USB hardware or PCB is part of this component. The separate voice-conversion application and model weights are not part of this source repository.
