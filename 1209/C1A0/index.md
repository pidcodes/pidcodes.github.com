Firmware for Metalclaw, a scriptable hardware-in-the-loop harness for embedded development running on RP2040 / RP2350 (Raspberry Pi Pico and compatible boards). It enumerates as a dynamic composite USB device with a MicroPython CDC REPL, an MSC volume, optional additional CDC serial ports (target console bridge), and vendor-specific bulk interfaces (including a CMSIS-DAP v2 SWD debug probe for probe-rs).
