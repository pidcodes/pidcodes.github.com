Firmware for a Raspberry Pi Pico 2 W (RP2350) that turns a phone into a USB keyboard:
the Blue-64 Keyboard app (iPhone / Android) connects via Bluetooth LE, the Pico appears
as a standard USB HID boot keyboard. PC / Mac layouts and a mode for the MiSTer C64 core.
Built with the Raspberry Pi Pico SDK, TinyUSB and BTstack. Hardware is an unmodified
Raspberry Pi Pico 2 W, no custom PCB.
