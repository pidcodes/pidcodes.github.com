Firmware for a Raspberry Pi Pico 2 W (RP2350) wired to the keyboard matrix of a
Commodore 64. Inside the C64 it types keys from the Blue-64 Keyboard app (Bluetooth LE)
and from Bluetooth keyboards / gamepads. Powered from USB without a C64, it turns the
original C64 keyboard into a standard USB HID keyboard (MiSTer C64 core, PC, Mac) with a
CDC serial console. Built with the Raspberry Pi Pico SDK, TinyUSB, BTstack and Bluepad32.
