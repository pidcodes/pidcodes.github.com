Tunnlix Key is a FIDO2/CTAP2.3-compliant USB authenticator,
self-validated using FIDO Alliance conformance tools. Its MIT-licensed
RP2350 firmware supports ES256, Ed25519, PIN verification,
discoverable credentials and credential management over FIDO USB HID.

The working reference hardware uses a Seeed Studio XIAO RP2350
with an external user-presence button between D0 (GPIO26) and GND.
