DuckPad is an Android app that turns a phone into a Bluetooth LE HID gamepad (HID over GATT) for Windows. The VID and PID are reported in the Device Information PnP ID characteristic, with the USB-IF vendor ID source, so hosts can identify the controller and game libraries such as SDL can map it.
