An open-source BL616 boot manager for a Bluetooth controller receiver. It exposes a vendor-defined USB HID management interface to select and inspect the receiver's firmware slots. This PID is for the management interface, not the controller's game-facing identity. The firmware targets existing development boards and is distributed as source code.
