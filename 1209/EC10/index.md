BenchPod is an open hardware bench tool for hardware-in-the-loop testing in CI: logic analyzer, analog I/O, CAN, sensor emulation and target power control, built on an STM32H563 and an iCE40 FPGA. Its USB port is a composite device (TinyUSB): a CDC-ACM console and a CDC-NCM network adapter that carries the pod's API. Hardware: https://github.com/embeddedci-com/benchpod (CERN-OHL-W-2.0). Firmware: https://github.com/embeddedci-com/benchpod-firmware (Apache-2.0).
