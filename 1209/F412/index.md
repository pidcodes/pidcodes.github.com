Open-source CircuitPython firmware for the ELECFREAKS Retro Arcade handheld,
which uses an STM32F412RET6 microcontroller. The firmware provides a USB serial
console and the CIRCUITPY USB mass-storage interface for loading Python programs.

This is an independently maintained software port for existing commercial hardware.
The PID identifies the CircuitPython application; the device's existing UF2
bootloader keeps its separate USB identity.
