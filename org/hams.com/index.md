Hams.com is an amateur radio service by Bruce Perens (K6BP), creator of the
Open Source Definition, which became the core of the Open Source Hardware
Definition.

Hams.com's open source projects include radio-control software, bench
instrument software, and open hardware and firmware for amateur radio
stations (https://github.com/BrucePerens/hams_open).
